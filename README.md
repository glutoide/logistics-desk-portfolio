# Logistics Desk — рабочее место диспетчера

**Независимый портфолио-проект**: компактная интерактивная демонстрация управления логистическими заявками. Реализован на чистом JavaScript, HTML и CSS; запускается без установки зависимостей и серверной инфраструктуры.

> **Демо не является исходным кодом SnowForce или его копией.** Это отдельно написанная иллюстрация задач, которые решались во время кандидатского проекта. Все названия компаний, объекты, цены и данные вымышлены. Код, настройки, история Git, доступы и компоненты частного репозитория заказчика не переносились.

### Что можно попробовать

- Открыть список заявок и фильтровать его по номеру, объекту, виду техники и статусу.
- Выбрать подрядчика и подходящую технику; демонстрационная модель отклоняет неподходящий тип и двойное бронирование на одно время.
- Перенести дату и время с записью изменения в историю.
- Перевести заявку из назначения в выполнение и зафиксировать фактическую стоимость.
- Добавить **название** подтверждающего документа. Сами файлы не загружаются и не сохраняются.
- Обновить страницу: состояние останется в `localStorage`. Кнопка «Сбросить демо» возвращает исходные данные.
- Открыть с телефона: интерфейс адаптируется под узкий экран.

### Устройство

```text
index.html              точка входа
styles.css              адаптивный интерфейс
src/app.mjs             представление и локальные действия
src/model.mjs           проверки правил, переходы состояний, история
tests/model.test.mjs    независимые unit-тесты на Node.js
```

Демонстрационная модель не использует никакой внешний API: приёмка интерфейса не зависит от рабочих сервисов заказчика. Все изменения локальны, не затрагивают реальные заказы или базы данных.

### Запуск

Нужен любой современный браузер. Для `type="module"` используйте простой HTTP-сервер в корне проекта:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`. Если Python недоступен, можно использовать любой статический HTTP-сервер.

Проверка модели (Node.js 20+):

```bash
node --test tests/model.test.mjs
```

### Границы демонстрации

Это **не production-сервис**: нет backend/API, настоящей авторизации, разграничения прав на сервере, загрузки файлов, синхронизации между пользователями, расчёта цен по реальным тарифам или интеграции с рабочей системой. Данные и рейтинги созданы исключительно для показа сценария.

**Авторский вклад:** постановка продуктовой задачи, описание сценариев и критериев, управление AI-assisted разработкой, проверка результата и исправление найденных несоответствий. Не заявляется, что весь исходный код написан вручную без ИИ.

### Контекст

Портфолио посвящено продуктовому подходу к рабочему месту логиста: одна заявка объединяет потребность, сроки, подходящую технику, назначение, ход выполнения и историю. Для публичного показа сделана **самостоятельная минимальная реализация**, без закрытого исходного кода и без «обвязки» исходного приложения.
